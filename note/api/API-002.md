`diana_status` (`include/diana/status.h`) has six codes. Every public function returns it except
`diana_status_str` and `diana_version`, which return `const char *`.

- `DIANA_OK` (0, `"ok"`): converged or completed.
- `DIANA_CONTINUE` (1, `"continue"`): from bisection and Newton `init`/`step` only; evaluate at
  `s->x` and call `step` again.
- `DIANA_ERR_ARG` (-1, `"invalid argument"`): any of them. NULL pointer, NaN or ±∞ input,
  out-of-range argument (`a > b`, `tol < 0`, `max_iter == 0`, `n`, `d`, `stage`), and also a
  non-finite result or overflow: `diana_trapezoidal`, `diana_simpson`, `diana_euler_step`,
  `diana_rk4_stage`, `diana_rk4_step`, the correction or iterate of `diana_newton_step`, and an
  entry of `diana_forward_substitution` or `diana_back_substitution` that overflows (API-030),
  an update of `diana_lu` that overflows (API-032), and a pivot row `piv[k] >= n` or an entry of
  either solve that overflows in `diana_lu_solve` (API-034).
- `DIANA_ERR_BRACKET` (-2, `"no sign change in bracket"`): `diana_bisection_init` and
  `diana_bisection`, when `fa` and `fb` have the same strict sign.
- `DIANA_ERR_MAXITER` (-3, `"iteration limit reached"`): bisection and Newton `step` and
  wrappers, when `iter` reaches `max_iter` before a stopping test holds.
- `DIANA_ERR_SINGULAR` (-4, `"zero derivative or pivot"`): `diana_newton_step` and
  `diana_newton`, when `f'(x)` is ±0 and `f(x)` is finite and non-zero; `diana_cholesky`, when a
  pivot is not positive (negative, ±0 or NaN, API-028); `diana_forward_substitution` and
  `diana_back_substitution`, when a diagonal entry is ±0 (API-030); `diana_lu`, when every
  candidate pivot of a column is ±0 (API-032); `diana_lu_solve`, when a diagonal entry of `U` is
  ±0 (API-034).

`diana_status_str(s)` returns one of those static strings, or `"unknown status"` for any other
value; never NULL (`src/status_str.c`). `diana_version()` is declared in `diana/diana.h`, not
`status.h`, and returns `DIANA_VERSION_STRING` as compiled into the library, so it names the
linked library rather than the header. `diana/diana.h` also defines `DIANA_VERSION_MAJOR`,
`DIANA_VERSION_MINOR` and `DIANA_VERSION_PATCH`; CMake configuration fails when any of them
disagrees with `project(diana VERSION ...)` in `CMakeLists.txt`.
