`diana_bisection_state` holds `a`, `b`, `fa`, `fb`, `x`, `tol` (double), `iter`, `max_iter`
(unsigned) and, last, `status` (`diana_status`). The caller reads the fields and must not write
them between calls.

- Invariant (`bisection_bracket` in `src/bisection_acsl.h`), after `DIANA_OK` or
  `DIANA_CONTINUE` from `init` and after every `step` other than `DIANA_ERR_ARG` (BISECTION-C2,
  C3): `a`, `b`, `fa`, `fb` finite, `a <= b`, `-DBL_MAX/2 <= a` and `b <= DBL_MAX/2`,
  `tol >= 0`, and either a strict sign change (`fa < 0 < fb` or `fa > 0 > fb`) or `a == b` with
  `fa == fb == 0`.
- `x` is the next evaluation point, strictly inside (`a < x < b`, predicate `bisection_next`),
  after `DIANA_CONTINUE`; after `DIANA_ERR_MAXITER` it is also the new interior midpoint. After
  `DIANA_OK` it may be an endpoint: `init` sets it to `a` or `b` when that f-value is zero, and
  the `fx == 0` and tolerance exits of `step` keep the evaluated `x`, which has just become an
  endpoint. The estimate is `diana_bisection_result`'s `0.5 * (a + b)`: `x² − 2` on `[0, 2]`
  with `tol = 1e-3` ends with `x == b == 1.4150390625` while the estimate is `1.41455078125`.
- `status` is the status of the last `init` or `step` that did not fail: `DIANA_OK` or
  `DIANA_CONTINUE` from `init`, `DIANA_OK`, `DIANA_CONTINUE` or `DIANA_ERR_MAXITER` from `step`;
  `DIANA_ERR_ARG` and `DIANA_ERR_BRACKET` leave it. `result` does not read it.
- `step` runs only on a state whose `status` is `DIANA_CONTINUE` and returns `DIANA_ERR_ARG`,
  state unchanged, for any other, so a finished state and a zero-initialized struct (status 0,
  `DIANA_OK`) are rejected. Its WP precondition is a valid `s` and, only when `status` is
  `DIANA_CONTINUE`, `bisection_bracket`, `bisection_next` and `iter < max_iter`.
- `iter` counts completed steps: 0 after `init`, plus 1 for every `step` other than
  `DIANA_ERR_ARG`. `tol` and `max_iter` keep their `init` values.
