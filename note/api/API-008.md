The tests run in source order, and the first that holds decides the status. `mid(a, b)` is
`diana_bisection_mid`, `0.5 * (a + b)` in binary64.

`diana_bisection_init(s, a, b, fa, fb, tol, max_iter)`:
1. `s` NULL; any of `a`, `b`, `fa`, `fb`, `tol` NaN or ±∞; `a > b`, `tol < 0` (`-0.0` passes)
   or `max_iter == 0`; `|a|` or `|b| > DBL_MAX/2`: `DIANA_ERR_ARG`, nothing written.
2. `fa`, `fb` both `> 0` or both `< 0`: `DIANA_ERR_BRACKET`, nothing written.
3. Write `a`, `b`, `fa`, `fb`, `tol`, `iter = 0`, `max_iter`, `x = mid(a, b)`.
4. `fa == 0`: collapse onto `a` (`b = a`, `fb = fa`, `x = a`), `DIANA_OK`. Then `fb == 0`:
   collapse onto `b`, `DIANA_OK`. Both zero collapses onto `a`.
5. `b - a <= tol`, or `x <= a` or `x >= b` (no double strictly inside): `DIANA_OK`.
6. Otherwise `DIANA_CONTINUE`.

`diana_bisection_step(s, fx)`:
1. `s` NULL or `fx` NaN or ±∞: `DIANA_ERR_ARG`, nothing written.
2. `iter += 1`.
3. `fx == 0`: `a = b = x`, `fa = fb = fx`, `DIANA_OK`.
4. `(fx > 0) == (fa > 0)` moves `a` to `x` (and `fa = fx`), otherwise `b` to `x` (`fb = fx`).
5. `b - a <= tol`: `DIANA_OK`, `x` not recomputed.
6. `x = mid(a, b)`; `x <= a` or `x >= b`: `DIANA_OK`.
7. `iter >= max_iter`: `DIANA_ERR_MAXITER`. Otherwise `DIANA_CONTINUE`.

Every convergence exit precedes the `max_iter` test, so a last step that converges returns
`DIANA_OK`. `diana_bisection_result(s, root, width)` returns `DIANA_ERR_ARG` for a NULL `s`,
otherwise writes `*root = mid(a, b)` and `*width = b - a` (rounded) for each non-NULL output
and returns `DIANA_OK`. VST proves each exit and written field (BISECTION-C8, C9, C7).
