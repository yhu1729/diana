`diana_newton_state` holds `x`, `dx`, `tol` (double), `iter`, `max_iter` (unsigned). Invariant
(`newton_state` in `src/newton_acsl.h`): `x`, `dx`, `tol` finite and `tol >= 0`.

`diana_newton_init(s, x0, tol, max_iter)`: `s` NULL, `x0` or `tol` NaN or ±∞, `tol < 0` or
`max_iter == 0` is `DIANA_ERR_ARG` with nothing written; otherwise `x = x0`, `dx = 0`,
`iter = 0` and `DIANA_CONTINUE`. It sees no f-value, so it never returns `DIANA_OK`.

`diana_newton_step(s, fx, dfx)`, first match wins:
1. `s` NULL, or `fx` or `dfx` NaN or ±∞: `DIANA_ERR_ARG`, nothing written. Finiteness comes
   first, so `fx == 0` with a NaN `dfx` is an error.
2. `fx == 0`: `dx = 0`, `iter += 1`, `x` unchanged, `DIANA_OK`, whatever the finite `dfx`.
3. `dfx == 0` (either sign): `DIANA_ERR_SINGULAR`, nothing written.
4. `dx = fx / dfx` NaN or ±∞ (overflow, e.g. a subnormal `dfx`): `DIANA_ERR_ARG`, nothing
   written. Then `x' = x - dx` not finite: `DIANA_ERR_ARG`, nothing written.
5. Store `iter += 1`, `dx`, `x = x'`. `DIANA_OK` if `x'` equals the old `x` (stagnation:
   `|dx| <= ulp(x)/2`, NEWTON-B3) or `|dx| <= tol`; else `DIANA_ERR_MAXITER` if
   `iter >= max_iter`; else `DIANA_CONTINUE`.

So `dx` is 0 after `init` and after a `fx == 0` step, and otherwise the last correction applied
(`x_new = x_old - dx`). The WP precondition of `step` is `newton_state` and `iter < max_iter`:
a call after `DIANA_ERR_MAXITER` is outside the contract, one after `DIANA_OK` only while
`iter < max_iter`.
`diana_newton_result(s, root, dx)` returns `DIANA_ERR_ARG` for a NULL `s`, otherwise writes
`*root = x` and `*dx = dx` for each non-NULL output and returns `DIANA_OK`. VST proves every exit
(NEWTON-C5, C6, C4), and that the stored `x` and `dx` are the Flocq `fstep` and `fdiv` (C7).
