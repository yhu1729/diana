`diana_newton_state` holds `x`, `dx`, `tol` (double), `iter`, `max_iter` (unsigned) and, last,
`status` (`diana_status`). Invariant (`newton_state` in `src/newton_acsl.h`): `x`, `dx`, `tol`
finite and `tol >= 0`.

`diana_newton_init(s, x0, tol, max_iter)`: `s` NULL, `x0` or `tol` NaN or ±∞, `tol < 0` or
`max_iter == 0` is `DIANA_ERR_ARG` with nothing written; otherwise `x = x0`, `dx = 0`,
`iter = 0`, `status = DIANA_CONTINUE` and `DIANA_CONTINUE`. It sees no f-value, so it never
returns `DIANA_OK`.

`diana_newton_step(s, fx, dfx)`, first match wins:
1. `s` NULL, `status != DIANA_CONTINUE`, or `fx` or `dfx` NaN or ±∞: `DIANA_ERR_ARG`, nothing
   written. Finiteness comes first, so `fx == 0` with a NaN `dfx` is an error.
2. `fx == 0`: `dx = 0`, `iter += 1`, `x` unchanged, `status = DIANA_OK`, `DIANA_OK`, whatever
   the finite `dfx`.
3. `dfx == 0` (either sign): `DIANA_ERR_SINGULAR`, nothing written.
4. `dx = fx / dfx` NaN or ±∞ (overflow, e.g. a subnormal `dfx`): `DIANA_ERR_OVERFLOW`, nothing
   written. Then `x' = x - dx` not finite: `DIANA_ERR_OVERFLOW`, nothing written. `fx` and `dfx`
   are finite and non-zero here, so only an overflow reaches this exit.
5. Store `iter += 1`, `dx`, `x = x'`. `DIANA_OK` if `x'` equals the old `x` (stagnation:
   `|dx| <= ulp(x)/2`, NEWTON-B3) or `|dx| <= tol`; else `DIANA_ERR_MAXITER` if
   `iter >= max_iter`; else `DIANA_CONTINUE`. `DIANA_OK` and `DIANA_ERR_MAXITER` are also
   written to `status`; on `DIANA_CONTINUE` it stays `DIANA_CONTINUE`.

So `dx` is 0 after `init` and after a `fx == 0` step, and otherwise the last correction applied
(`x_new = x_old - dx`). A finished state (`DIANA_OK`, `DIANA_ERR_MAXITER`) or a zero-initialized
one (status 0, `DIANA_OK`) is rejected by exit 1; the WP precondition of `step` asks
`newton_state` and `iter < max_iter` only when `status` is `DIANA_CONTINUE`.
`diana_newton_result(s, root, dx)` returns `DIANA_ERR_ARG` for a NULL `s`, otherwise writes
`*root = x` and `*dx = dx` for each non-NULL output and returns `DIANA_OK`, whatever `status`
holds. VST proves every exit (NEWTON-C5, C6, C4), and that the stored `x` and `dx` are the Flocq
`fstep` and `fdiv` (C7).
