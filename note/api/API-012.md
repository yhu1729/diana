---
id: API-012
title: Newton wrapper resets the derivative before each call
kind: fact
path:
  - src/newton.c
  - test/c/test_newton.c
related: [API-006, API-010, API-003]
---
`diana_newton(f, ctx, x0, tol, max_iter, root, iter)` calls `f(x, &dfx, ctx)` once per step,
after setting `dfx = 0.0`, so a callback that never writes `*dfx` yields a zero derivative
rather than an indeterminate read.

1. `*iter = 0` if `iter` is non-NULL.
2. `f` or `root` NULL: `DIANA_ERR_ARG`, `f` not called.
3. `diana_newton_init`; `DIANA_ERR_ARG` returns at once, `f` not called, `*iter = 0`.
4. While `DIANA_CONTINUE`: `dfx = 0.0`, `fx = f(s.x, &dfx, ctx)`, `diana_newton_step(&s, fx,
   dfx)`.
5. `*iter = s.iter`, the completed steps; a step that fails is not counted.
6. `DIANA_ERR_ARG` or `DIANA_ERR_SINGULAR` returns without writing `*root`. On `DIANA_OK` or
   `DIANA_ERR_MAXITER`, `*root = s.x`, then that status is returned.

A callback that never writes `*dfx` therefore fails with `DIANA_ERR_SINGULAR` on the first step
only when `f(x0)` is finite and non-zero; `f(x0) == 0` gives `DIANA_OK` (API-010, exit 2), and a
non-finite `f(x0)` gives `DIANA_ERR_ARG`. `test_wrapper_error` in `test/c/test_newton.c` covers
the NULL, init-error, zero-derivative and unwritten-derivative cases, and a NaN on the second
call (`DIANA_ERR_ARG`, `*iter == 1`, `*root` untouched).
