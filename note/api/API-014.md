`diana_simpson(y, n, h, result)` needs an odd `n >= 3` (an even number `n - 1` of panels) and
evaluates, in binary64 and in this order, with `p = n / 2`:

1. `so = +0`, then `so = so + y[2k + 1]` for `k = 0, ..., p-1` (odd samples, left to right);
2. `se = +0`, then `se = se + y[2k]` for `k = 1, ..., p-1` (even interior samples; none when
   `n == 3`);
3. `s = ((y[0] + y[n-1]) + 4.0 * so) + 2.0 * se`;
4. `r = (h * s) / 3.0` (the C `h * s / 3.0`), a correctly rounded division, not a product with
   a rounded `1/3`.

Exits: `y` NULL, `result` NULL, `n < 3` or `n` even is `DIANA_ERR_ARG` before any read; then
only `r` is checked: NaN or ±∞ is `DIANA_ERR_ARG` with `*result` unchanged, otherwise
`*result = r` and `DIANA_OK`.

- A non-finite sample or `h`, or an overflow in any operation, is an error. That includes
  `h * s` overflowing when `(h * s) / 3` would be finite. A finite `r` certifies every
  intermediate finite (SIMPSON-B1).
- `4.0 * so` and `2.0 * se` are exact unless they overflow; the two sums are independent.
- `y[0 .. n-1]` is only read and must not overlap `*result` (API-004); `h` may have either sign.
