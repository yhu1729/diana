`diana_euler_step(y, f, d, h, y_out)` computes `y_out[i] = y[i] + h * f[i]` for
`i = 0, ..., d-1`, the product rounded before the sum (`-ffp-contract=off`, no FMA), and writes
nothing unless every component is finite.

1. `y`, `f` or `y_out` NULL, or `d == 0`: `DIANA_ERR_ARG`, nothing read or written.
2. First pass: for each `i`, compute `r = y[i] + h * f[i]` and test it with `diana_fp_finite`.
   At the first NaN or ±∞ it tests `h`, then `y[j]` and `f[j]` for `j = 0, ..., d-1`: the first
   non-finite one returns `DIANA_ERR_ARG`, none `DIANA_ERR_OVERFLOW`; `y_out` is untouched on
   both (API-036).
3. Second pass: recompute each component, bit for bit the same, store it; `DIANA_OK`.

- A NaN or infinite `y[i]`, `f[i]` or `h` is `DIANA_ERR_ARG`, an overflow in the product or the
  sum of finite inputs `DIANA_ERR_OVERFLOW` (EULER-B1: a finite component certifies both
  operations). Underflow is not an error.
- `y` and `f` are only read and may overlap each other; `y_out` must not overlap either
  (API-004), which also keeps the inputs unchanged between the two passes.
- The step is one component-wise call; the caller evaluates `f = F(t, y)` and loops, or uses
  `diana_euler` (API-017). `diana_euler_step_unchecked` is the one-pass variant (API-018).
