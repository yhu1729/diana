Per RK4 step the caller evaluates `k1 = F(t, y)`, `k2 = F(t + h/2, Y2)`, `k3 = F(t + h/2, Y3)`,
`k4 = F(t + h, Y4)`; the kernel builds `Y2`, `Y3`, `Y4` and combines the slopes. Both functions
make the two passes of `diana_euler_step` (API-015): check every component, then write.

`diana_rk4_stage(y, k, d, h, stage, y_out)`:
1. `y`, `k` or `y_out` NULL, `d == 0`, or `stage` not 2, 3 or 4: `DIANA_ERR_ARG`.
2. Coefficient computed once: `c = h` for stage 4, `c = 0.5 * h` for stages 2 and 3. `0.5 * h`
   is exact whenever `|h| >= 2⁻¹⁰²¹`, and otherwise within `2⁻¹⁰⁷⁵` of `h/2` (RK4-B2).
3. Component `y[i] + c * k[i]`, product rounded first; at the first NaN or ±∞, `DIANA_ERR_ARG`
   if `h` or any `y[j]`, `k[j]` is not finite, else `DIANA_ERR_OVERFLOW`, `y_out` untouched on
   both; else written, `DIANA_OK`. Pass `k1` for stage 2, `k2` for 3, `k3` for 4.

`diana_rk4_step(y, k1, k2, k3, k4, d, h, y_out)`:
1. Any pointer NULL or `d == 0`: `DIANA_ERR_ARG`.
2. Component `s = (k1[i] + k4[i]) + 2.0 * (k2[i] + k3[i])`, then `y[i] + (h * s) / 6.0` (the C
   `y[i] + h * s / 6.0`), each operation rounded in that order; the doubling is exact unless it
   overflows.
3. At the first component NaN or ±∞: `DIANA_ERR_ARG` if `h` or any `y[j]`, `k1[j]` to `k4[j]`
   is not finite, else `DIANA_ERR_OVERFLOW`, `y_out` untouched on both; else written, `DIANA_OK`.

A NaN or infinite input is `DIANA_ERR_ARG` and an overflow in any operation on finite inputs
`DIANA_ERR_OVERFLOW` (API-036), including `h * s` when `(h * s) / 6` would be finite; a finite
component certifies every operation (RK4-B1, RK4-B4).
Underflow is not an error. `y_out` must not overlap `y` or any slope; inputs may overlap each
other (API-004). The stage times are the caller's; the kernel never sees `t`.
