An array argument (`y` of `trapezoidal` and `simpson`; `y`, `f` of `euler_step`; `y`, `k` of
`rk4_stage`; `y`, `k1` to `k4` of `rk4_step`; `a` of `cholesky` and `lu`; `lower`, `b` of
`forward_substitution` and `transpose_substitution`; `lu`, `b` of `lu_solve`) that supports the
buffer protocol (`isinstance(v, collections.abc.Buffer)`) is read in place, without a copy. Any
other iterable is first copied by the Python driver into `array.array("d", v)`.

`diana_py_get_array` (`python/ext/get_array.c`) requests the buffer with `PyBUF_RECORDS_RO` and
checks, in this order, with messages naming the argument:
1. format `d`, optionally prefixed by `@`, `=` or the native byte-order character, and itemsize
   8 (a missing format counts as `B`): else `TypeError`, `y must be a buffer of native float64
   (format 'd'), not format 'f'`. `bytes` (`B`), `int64` arrays and `>d` on a little-endian
   host fail here.
2. one dimension: else `ValueError` (`y must be one-dimensional, not 2-D`);
3. at least the minimum length (2 for `trapezoidal`, 3 for `simpson`, 1 otherwise): else
   `ValueError`;
4. C-contiguous: else `ValueError` (`y must be C-contiguous`);
5. start address aligned for `double`: else `ValueError` (`y is not aligned for float64`).

Then come per-function checks: an even length for `simpson`, unequal lengths for the ODE functions,
a length that is not a square for `cholesky` and `lu`, a `lower` (or `lu` of `lu_solve`) whose
length is not `len(b)**2` for the substitution functions and `lu_solve` (`ValueError`). The pivot
rows `piv` of `lu_solve` are not an array argument but any iterable of `int` (API-035). For
`rk4_stage` the extension converts `h` and range-checks `stage` before any buffer check. The copy
`array.array("d", v)` converts each element through `__float__` or `__index__` (an int rounds to the
nearest double) and raises its own errors: `TypeError` for a `str` element or a `str` `v`,
`OverflowError` for an int beyond the double range. A buffer of another type or layout is rejected,
never converted: use `astype(np.float64)` or `np.ascontiguousarray` first. The package depends on
nothing (`dependencies = []`); NumPy is used only in tests.
