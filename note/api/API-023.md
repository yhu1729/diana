`diana.Bisection(a, b, fa, fb, tol=0.0, max_iter=2100)` and `diana.Newton(x0, tol,
max_iter=100)` wrap the C state and add a `status` field, the last status code.

- `__new__` sets `status = ERR_ARG`, the not-initialized marker; while it holds, `step` and
  `result` raise `RuntimeError`. `__init__` stores the C `init` status (`OK` or `CONTINUE` for
  bisection, `CONTINUE` for Newton) only on success. A failed `__init__`, in conversion or in the
  C `init`, leaves the C state and `status` as they were, since the C `init` writes nothing on
  error; an initialized object stays usable, and `__init__` may be called again to restart.
- `step` is positional-only: `Bisection.step(fx)`, `Newton.step(fx, dfx)`; a keyword is
  `TypeError`. It checks, in order: initialized (`RuntimeError`); converts the arguments
  (`TypeError`); `status == CONTINUE`, else `RuntimeError: step called on a finished ... state`,
  even for a Newton state that is `OK` with `iter < max_iter`; then calls the C `step`.
- `ERR_ARG` and `ERR_SINGULAR` from the C `step` raise (API-022) with the state unchanged and
  `status` still `CONTINUE`, so the step can be retried. Otherwise the new status is stored and
  returned, so `step` returns only `OK`, `CONTINUE` or `ERR_MAXITER`.
- `result()` returns `(root, width)` or `(root, dx)` in any initialized state, mid-run and after
  `ERR_MAXITER` included.
- The C fields (`a b fa fb x tol iter max_iter`; `x dx tol iter max_iter`) and `status` are
  read-only attributes (`AttributeError: readonly attribute`).
- The types cannot be subclassed and cannot be pickled.
