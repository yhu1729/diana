`diana.Bisection(a, b, fa, fb, tol=0.0, max_iter=2100)` and `diana.Newton(x0, tol,
max_iter=100)` wrap the C state; their `status` attribute is the C field `s.status`, the last
status code, which the extension never writes after `__new__`.

- `__new__` sets `status = ERR_ARG`, the not-initialized marker, which no C call writes; while it
  holds, `step` and `result` raise `RuntimeError`. A successful `__init__` leaves the C `init`
  status in the field (`OK` or `CONTINUE` for bisection, `CONTINUE` for Newton). A failed
  `__init__`, in conversion or in the C `init`, leaves the C state, `status` included, as it was,
  since the C `init` writes nothing on error; an initialized object stays usable, and `__init__`
  may be called again to restart.
- `step` is positional-only: `Bisection.step(fx)`, `Newton.step(fx, dfx)`; a keyword is
  `TypeError`. It checks, in order: initialized (`RuntimeError`); converts the arguments
  (`TypeError`); `status == CONTINUE`, else `RuntimeError: step called on a finished ... state`
  (the C `step` would return `DIANA_ERR_ARG`); then calls the C `step`.
- `ERR_ARG`, `ERR_SINGULAR` and (Newton) `ERR_OVERFLOW` from the C `step` raise (API-022) with
  the state unchanged and `status` still `CONTINUE`, so the step can be retried. Otherwise the C
  `step` has written its result to `status` and it is returned, so `step` returns only `OK`,
  `CONTINUE` or `ERR_MAXITER`.
- `result()` returns `(root, width)` or `(root, dx)` in any initialized state, mid-run and after
  `ERR_MAXITER` included.
- The C fields (`a b fa fb x tol iter max_iter status`; `x dx tol iter max_iter status`) are
  read-only attributes (`AttributeError: readonly attribute`).
- The types cannot be subclassed and cannot be pickled.
