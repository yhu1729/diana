`diana.version()` returns `diana_version()` of the linked C library, and `diana.__version__` is
that value, read once at import.

- `test_version_consistent` (`test/python/test_status.py`) requires `project(diana VERSION ...)`
  in `CMakeLists.txt`, `DIANA_VERSION_STRING` in `include/diana/diana.h`, `version` in
  `pyproject.toml` and `diana.version()` to agree.
- `diana.OK`, `CONTINUE`, `ERR_ARG`, `ERR_BRACKET`, `ERR_MAXITER` and `ERR_SINGULAR` are module
  integers with the C values (0, 1, -1, -2, -3, -4), added in `python/ext/status_exec.c`.
  `status` and the return of `step` use them; `ERR_ARG` appears in `status` only before
  initialization (API-023).
- `diana.status_str(code)` (positional-only) returns `diana_status_str` of any C `int`:
  `status_str(12345) == "unknown status"`. Conversion errors are in API-021.
- `diana.__all__` lists the public names: the constants, `Bisection`, `Newton`, `BracketError`,
  `MaxIterError`, `SingularError`, `bisection`, `newton`, `trapezoidal`, `simpson`,
  `euler_step`, `euler`, `rk4_stage`, `rk4_step`, `rk4`, `cholesky`, `forward_substitution`,
  `back_substitution`, `lu`, `lu_solve`, `status_str`, `version` and `__version__`.
