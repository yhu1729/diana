`diana_forward_substitution(l, n, b, x)` solves `L·x = b` and `diana_back_substitution(l, n, b, x)`
solves `Lᵀ·x = b` for the `n×n` lower-triangular `L` stored column-major, `l[i + k*n] = L[i, k]`,
the layout `diana_cholesky` writes. Exits in order, the same in both:

1. `l`, `b` or `x` NULL, `n == 0`, or `n > (size_t)-1 / n`: `DIANA_ERR_ARG`, nothing read or
   written.
2. Column `j = 0, …, n-1`, row `i = j, …, n-1`: the first `l[i + j*n]` that `diana_fp_finite`
   rejects is `DIANA_ERR_ARG`; then the first non-finite `b[i]`, `i = 0, …, n-1`, is
   `DIANA_ERR_ARG`; then the first `i` with `l[i + i*n] == 0.0` (`+0` or `-0`) is
   `DIANA_ERR_SINGULAR`. `x` is untouched on all three (SUBSTITUTION-C1 to C4); the strict upper
   triangle of `l` is never read.
3. Forward, `i = 0, …, n-1`: `s = b[i]`, `s = s - l[i + k*n] * x[k]` for `k = 0, …, i-1`, the
   product rounded first, `r = s / l[i + i*n]`; a non-finite `r` returns `DIANA_ERR_OVERFLOW`
   (the inputs are finite here), else `x[i] = r`. Back, `i = n-1, …, 0`: the same with
   `s = s - l[k + i*n] * x[k]` for `k = n-1` down to `i+1`.
4. `DIANA_OK`: every `x[i]` finite.

- The overflow exit of step 3 has written `x[0 .. i-1]` (forward) or `x[i+1 .. n-1]` (back), the
  model entries, and left the rest as the caller had it (SUBSTITUTION-C3, C4); the API calls the
  contents unspecified. Underflow, a subnormal or `±0` entry, is not an error.
- A finite `r` certifies its row: an infinite or NaN product or partial sum stays non-finite
  through the later subtractions and the division by a finite nonzero diagonal entry.
- Back substitution is forward substitution on the mirrored system `L′[p, q] = L[n-1-q, n-1-p]`,
  `b′[p] = b[n-1-p]`, bit for bit (`fbwd`, PROOF-010).
- The solve reads back entries of `x` it has written, so `x` must not overlap `l` or `b` (API-004).
