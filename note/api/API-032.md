`diana_lu(a, n, lu, piv)` (`src/lu.c`) factors the `n×n` matrix stored column-major,
`a[i + j*n] = A[i, j]`, into the packed factor in `lu` (same layout: `L` strictly below the
diagonal, its unit diagonal not stored, `U` on and above it) and the pivot rows in `piv`. Exits
in order:

1. `a`, `lu` or `piv` NULL, `n == 0`, or `n > (size_t)-1 / n`: `DIANA_ERR_ARG`, nothing read or
   written.
2. Validation, linear index `q = 0, …, n*n-1`: the first `a[q]` that `diana_fp_finite` rejects is
   `DIANA_ERR_ARG` with `lu` and `piv` untouched (LU-C1, C2). Every entry is read, the strict
   upper triangle included. Then `lu[q] = a[q]` for every `q`.
3. Step `k = 0, …, n-1`:
   - `p = k`, `m = 0.0`; for `i = k, …, n-1`, `v = lu[i + k*n]`, `v = -v` if `v < 0.0` (so `-0`
     stays `-0`), and `p = i`, `m = v` if `v > m`: the first row of largest magnitude, `p = k`
     for a zero column. `m == 0.0` returns `DIANA_ERR_SINGULAR`.
   - `piv[k] = p`; rows `k` and `p` are interchanged in every column `j = 0, …, n-1`, through a
     temporary, also when `p == k`.
   - `d = lu[k + k*n]` and `lu[i + k*n] = lu[i + k*n] / d` for `i > k`, a division rather than a
     product with `1/d`.
   - for `j = k+1, …, n-1` (`u = lu[k + j*n]`) and `i = k+1, …, n-1`:
     `t = lu[i + j*n] - lu[i + k*n] * u`, the product rounded first; a non-finite `t` returns
     `DIANA_ERR_OVERFLOW` before it is stored (every entry of `a` is finite here).
4. `DIANA_OK`: every entry of `lu` finite (LU-B1) and `k <= piv[k] < n` (LU-C1).

- After `DIANA_ERR_SINGULAR` at step `k`, or the overflow exit, `lu` holds the working matrix part
  way through the computation and `piv[0 .. k-1]` the earlier pivot rows; the API calls both
  unspecified and VST proves only their lengths (LU-C2).
- The multipliers are not checked: each has magnitude at most 1 (LU-B2), so it is finite, and the
  pivot row holds copies of `a` or earlier checked updates.
- `lu` and `piv` must not overlap `a` or each other (API-004).
- `diana_lu_solve` takes `lu` and `piv` as written here and solves `A·x = b` (API-034).
