`diana_lu_solve(lu, piv, n, b, x)` (`src/lu_solve.c`) solves `A·x = b` from the packed factor
`lu` and pivot rows `piv` that `diana_lu` writes (API-032), `lu[i + k*n]` column-major. Exits in
order:

1. `lu`, `piv`, `b` or `x` NULL, `n == 0`, or `n > (size_t)-1 / n`: `DIANA_ERR_ARG`, nothing read
   or written.
2. Validation, `x` untouched on every exit (LU-SOLVE-C1, C2): the first `lu[q]`,
   `q = 0, …, n*n-1`, that `diana_fp_finite` rejects, then the first `piv[k] >= n`, then the first
   non-finite `b[i]`, is `DIANA_ERR_ARG`; then the first `i` with `lu[i + i*n] == 0.0` (`+0` or
   `-0`) is `DIANA_ERR_SINGULAR`. Every entry of `lu` is read, both triangles.
3. `x[i] = b[i]` for every `i`, then for `k = 0, …, n-1`: `p = piv[k]`, `t = x[k]`,
   `x[k] = x[p]`, `x[p] = t`. Only `piv[k] < n` is required: any such values are a sequence of
   interchanges, a permutation (LU-SOLVE-A1); `diana_lu` writes `k <= piv[k]`.
4. Forward, `i = 0, …, n-1`: `s = x[i]`, `s = s - lu[i + k*n] * x[k]` for `k = 0, …, i-1`, the
   product rounded first, no division; a non-finite `s` returns `DIANA_ERR_OVERFLOW`, else
   `x[i] = s`; the inputs are finite here, so only an overflow reaches this exit or the next.
5. Back, `i = n-1, …, 0`: `s = x[i]`, `s = s - lu[i + k*n] * x[k]` for `k = n-1` down to `i+1`,
   `r = s / lu[i + i*n]`; a non-finite `r` returns `DIANA_ERR_OVERFLOW`, else `x[i] = r`.
6. `DIANA_OK`: every `x[i]` finite.

- The overflow exit of step 4 has written `x[0 .. i-1]` (the solve `y`) and left `x[i .. n-1]`
  holding `P·b`; that of step 5 has written `y[0 .. i]` and `x[i+1 .. n-1]` (LU-SOLVE-C2). The API
  calls the contents unspecified (API-003).
- Steps 4 and 5 are `diana_forward_substitution` with the unit lower factor and
  `diana_back_substitution` with the transposed upper factor bit for bit: the division by 1 the
  former performs is exact on a finite value.
- `x` must not overlap `lu`, `piv` or `b` (API-004): the solve works in place in `x`.
