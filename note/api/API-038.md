`diana.norm_1(x)`, `diana.norm_2(x)` and `diana.norm_inf(x)` return the C result as a `float`.
`x` is an array argument (API-020) of any length; a non-buffer iterable is copied into
`array.array("d")` by `_samples` in `python/src/diana/_norm.py`.

- The extension functions `diana._diana.norm_1`, `norm_2` and `norm_inf` take one buffer `x`
  (keyword `x`) and pass their kernel to `diana_py_norm` (`python/ext/norm.c`), which reads the
  buffer with `diana_py_get_array` (minimum length 0) and calls the kernel.
- An empty buffer may expose a pointer that is not aligned for `double` (an empty `array.array`
  points at a one-byte static buffer), so `diana_py_get_array` skips the alignment check for
  length 0 and `diana_py_norm` passes the address of a local `0.0` instead: the kernel rejects a
  NULL `x` even for `n == 0`.
- `DIANA_ERR_ARG` raises `ValueError` (`x has a non-finite entry`), `DIANA_ERR_OVERFLOW`
  `diana.FloatOverflowError` (`the norm overflows`, API-022).
- The GIL is held during the call, as for every array function.
