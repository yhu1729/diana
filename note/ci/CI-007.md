`style_python` (template `.uv`) runs, in order:

1. `uv sync --group lint --group spec`, which also builds and installs the `diana` package with
   `DIANA_WERROR=ON` (the template's `SKBUILD_CMAKE_DEFINE`);
2. `ruff check` and `ruff format --check` over `python`, `test/python`, `test/doc` and `script`
   (STYLE-009);
3. `uv run script/check_spec.py --no-report`: without `--run` the gate is structural, it validates
   every `spec/*.md` front matter (GATE-001) and writes the prover check files but runs no prover;
4. `uv run script/check_doc.py`: note front matter, note index, note IDs and relative Markdown
   links (STYLE-003), without `--write`, so a stale index fails.

`--no-report` changes nothing in step 3: only a `--run` of every prover rewrites
`doc/verification/report.md`, and no CI job runs both provers (`verify_lean` runs Lean alone,
also with `--no-report`). The report is therefore regenerated locally and committed (GATE-006).
Path list `.change_style` (CI-002), which includes `README.md`, `CONTRIBUTING.md`, `doc/`, `note/`
and `spec/` for the doc check, and `.github/workflows/`, since a note's `path` may name a workflow.
