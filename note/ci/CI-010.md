title: coverage_c and coverage_python rebuild with --coverage
kind: fact
path:
  - .gitlab-ci.yml
related: [CI-002, TEST-001]
---
Both `report`-stage jobs (template `.uv`) rebuild with `--coverage` instead of reusing a test
artifact; their needs (`test_gcc_debug`, `test_python`) are optional and fetch no artifacts. They
run on every default-branch pipeline besides `.rule_full` and their path list (CI-002).

- `coverage_c` configures `build` as Debug with `DIANA_BUILD_TEST=ON`, `DIANA_WERROR=ON`,
  `DIANA_BUILD_PYTHON=OFF`, `CMAKE_C_FLAGS=--coverage` and `CMAKE_EXE_LINKER_FLAGS=--coverage`,
  with the image's system compiler and no sanitizer (`DIANA_SANITIZER` defaults to OFF); runs
  ctest; then `gcovr` filtered to `src/` and `include/`, excluding the compiler-identification
  sources under `CMakeFiles/<version>/`. The job's coverage value is gcovr's `lines:` summary,
  the line rate.
- `coverage_python` sets `SKBUILD_CMAKE_DEFINE` to
  `DIANA_WERROR=ON;CMAKE_C_FLAGS=--coverage;CMAKE_MODULE_LINKER_FLAGS=--coverage`, rebuilds the
  package (`uv sync --group test --group coverage --reinstall-package diana`), runs
  `pytest --cov=diana --cov-branch`, then `gcovr` over scikit-build's `build/` filtered to
  `python/ext/`. The job's coverage value is the `TOTAL` percentage of pytest-cov's terminal
  report: with `--cov-branch` that combines statements and branches of the Python package, so it
  is not a line rate and excludes the extension.

Cobertura reports `coverage/c.xml`, `coverage/python.xml` (Python) and `coverage/python-c.xml`
(extension) are `coverage_report` artifacts, which GitLab shows in the merge-request diff; the
whole `coverage/` directory, HTML included, is kept a month.
