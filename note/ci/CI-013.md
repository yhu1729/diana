`verify_rocq` (image `$ROCQ_IMAGE`, `mathcomp/mathcomp:2.6.0-rocq-prover-9.2`, `needs: []`,
timeout 1 h) first apt-installs `python3` and `python3-yaml` with `sudo`: the image runs as the
user `rocq`, a sudoer with an empty password, and has no Python. Then it runs `rocq --version`,
`opam update -y rocq-released` and one `opam install -y coq-coquelicot.$COQUELICOT_VERSION
coq-flocq.$FLOCQ_VERSION` (3.4.5 and 4.2.2, the local versions), so both come from the current
index in a single solve. Coquelicot gives layer A real integrals and derivatives, Flocq is layer B.

- `make float` in `verification/rocq` builds every `theory/Real/*.v` and `theory/Float/*.v` file
  listed in `_CoqProject` (PROVER-007).
- `python3 script/check_spec.py --run --strict --prover rocq --layer A --layer B --no-report`
  writes a `CheckSpec.v` that names only the layer-A and layer-B theorems, compiles it with
  `make -s check_float` and checks their axioms (GATE-007). An `Admitted` lemma, an axiom outside
  `script/axiom_allow.yaml` or a listed constant missing from `theory/Real/` or `theory/Float/`
  fails the job. It runs under the image's Debian bookworm `python3` (3.11), as `verify_lean`
  does (CI-012).

No CI image carries CompCert or VST, so every CI image is a public stock one; the VST proofs,
their part of the Rocq axiom gate and the Clight AST are checked only locally (VERIFY-001). Path
list `.change_rocq`: `verification/rocq/**`, `spec/`, `script/check_spec.py`,
`script/check_provenance.py` (the gate imports it) and `script/axiom_allow.yaml`; a change to the
VST theories also runs the job although it builds none of them.
