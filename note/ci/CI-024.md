GitLab's `test_python` uses only the Python of `.python-version` (3.13). The GitHub `test_python`
job is a matrix over every minor version `requires-python = ">=3.12"` admits today, 3.12, 3.13
and 3.14, each leg in the uv image of its version
(`ghcr.io/astral-sh/uv:python3.<minor>-bookworm-slim`, digest-pinned). `UV_PYTHON` is the leg's
version: it overrides `.python-version` for `uv sync`, `uv run` and `uv build`, and
`script/check_wheel.py` builds and installs its wheels for `sys.executable`, the same
interpreter. `uv.lock` has wheels of every compiled dependency (NumPy, PyYAML and the rest) for
all three versions, so no leg builds one from source.

`test_python_macos` and `coverage_python` use 3.13 only. When a CPython release or a change of
`requires-python` changes the set, add or drop a leg with its image digest (CI-025).
