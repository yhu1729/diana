`src/fp.h` defines two `static inline` helpers in pure IEEE arithmetic, which Flocq models
exactly and which need no external call.

- `diana_fp_finite(x)` is `x == x && (x - x) == 0.0` and returns 1 or 0. `x == x` is false only
  for NaN; `x - x` is NaN for ±∞ and `+0` for every finite `x`, so both together mean finite.
  ACSL: `\result == 1 <==> \is_finite(x)`.
- `diana_fp_abs(x)` is `x < 0.0 ? -x : x`, with `requires \is_finite(x)` and
  `ensures \result == \abs(x)`. For `-0.0` it returns `-0.0` (the comparison is false), which
  compares equal to `0`; VST therefore specifies it as this conditional negation (`c_abs`), not
  as `Float.abs`, and `c_abs_B2R` identifies it with `Rabs` on finite input.
- Users: `diana_fp_finite` in every checked kernel source; `diana_fp_abs` only in
  `src/bisection_init.c` (`|a|`, `|b|` against `DBL_MAX / 2`) and `src/newton_step.c`
  (`|dx| <= tol`), where the sign of a zero result does not matter.

`clightgen` emits each helper as a real function into the AST of every source that calls it, so
each copy is a listed VST theorem of that source's spec: BISECTION-C5/C6 (`bisection_init`),
BISECTION-C13, NEWTON-C8 to C10, EULER-C3, RK4-C7/C8, TRAPEZOIDAL-C3, SIMPSON-C3.
