title: No push, tag or merge request without an explicit request
kind: rule
path:

Do not push, create or push a tag, open a merge request or merge without an explicit request from
the maintainer. A pushed tag matching `v<major>.<minor>.<patch>` starts a full pipeline and the
`release` job, which creates a GitLab release (CI-014).

Changes are proposed from a branch off `main` as a merge request on GitLab
(`https://gitlab.com/yhu1729/diana`); a bug report or a new method is discussed in its issues
before implementation. A pushed branch runs no CI until its merge request exists, and
merge-request pipelines keep the path filters (CI-001, CI-002).

Before a change lands, the `pre-push` hook (GIT-006) checks its commits, and `CONTRIBUTING.md`
asks for `script/dev.sh test` before every commit and `script/dev.sh verify` after a change to
`src/`, `include/`, `verification/`, `spec/`, `script/axiom_allow.yaml` or
`script/run_frama_c.sh`, since layer C-VST, its part of the Rocq axiom gate and
the Clight AST are checked only locally (VERIFY-001).
