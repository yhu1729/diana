id: VERIFY-005
title: On a fresh clone the spec gate must run before make check
kind: fact
path:
  - verification/rocq/Makefile
  - script/check_spec.py
  - .gitignore
related: [GATE-003, PROVER-007, VERIFY-002]
---
`verification/rocq/CheckSpec.v` and `verification/lean/CheckSpec.lean` are written by
`script/check_spec.py` and git-ignored, so a fresh clone has neither, and `make check` (or
`check_real`, `check_float`) in `verification/rocq` fails until the gate has written
`CheckSpec.v`.

- Any gate run that passes the structural check writes both files, so
  `uv run script/check_spec.py` is enough; `--run --prover rocq` also runs `make -s check`.
- `script/dev.sh verify` already orders this: its Rocq stage runs `make`, not `make check`, and
  the spec gate, run last, writes `CheckSpec.v` before it calls `make -s check`; CI
  `verify_rocq` likewise runs `make float`, then the gate, which calls `make -s check_float`.
- A `CheckSpec.v` written with `--layer A --layer B` names no VST theorem, so a hand-run
  `make check` afterwards prints only those layers until a full gate run rewrites it.
- After a change to `spec/`, a hand-run `make check` prints the axioms of the old list until the
  gate rewrites the file.
- `Makefile.rocq`, generated by the first `make`, is git-ignored as well.
