title: One VST file per verified source plus AST-free model files per method

Each VST-verified source file has its own proof file `verification/rocq/theory/VST/<Function>.v`,
the CamelCase source name (`src/bisection_init.c` gives `BisectionInit.v`, `src/rk4_step.c`
gives `RK4Step.v`). It imports that source's AST and holds the funspec and the `semax_body`
lemmas of every function in the AST. The C-order models (`c_init`, `c_step`, `c_euler`,
`c_stage`, `c_rk4`) and the lemmas a method's proof files share are in an AST-free
`VST/<Method>.v`, which imports no Clight module.

- AST-free files: `VST/Bisection.v`, `VST/Euler.v`, `VST/Newton.v`, `VST/RK4.v`.
  `VST/Bisection.v` also holds float-comparison lemmas that the `diana_fp_finite` proofs of
  other methods reuse; `VST/Tactic.v` holds shared tactics.
- Simpson, the trapezoidal rule and Cholesky are one kernel file each, so `VST/Simpson.v`,
  `VST/Trapezoidal.v` and `VST/Cholesky.v` hold model and proof together; the Cholesky model is
  the Flocq one instantiated with CompCert's NaN functions. The helper `src/fp_sqrt.c` has
  `VST/FpSqrt.v`.
- A variant has its own AST, proof file, Flocq file and spec (`spec/euler_unchecked.md`,
  `spec/rk4_unchecked.md`) but reuses its method's models: `VST/EulerStepUnchecked.v` imports
  `VST/Euler.v`, the RK4 unchecked proofs import `VST/RK4.v`.
- The `kernel` field of `spec/<method>.md` lists the method's source files
  (`spec/bisection.md`: `src/bisection_mid.c`, `src/bisection_init.c`, `src/bisection_step.c`,
  `src/bisection_result.c`).
- Every AST and proof file is listed in `verification/rocq/_CoqProject`; `make` builds only
  what is listed there.
