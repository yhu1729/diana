title: Each fp.h helper copy in a Clight AST is a listed VST theorem

path:

`clightgen` emits a copy of each `src/fp.h` helper that a source uses into that source's AST, and
a caller's `semax_body` only assumes the helper's funspec. So each copy has its own
`body_diana_fp_*` lemma in the source's VST file and is a listed layer-C theorem of the method's
spec; otherwise an admitted copy would pass unnoticed.

| AST | Copies | Theorems |
|---|---|---|
| `axpy` | `diana_fp_finite` | AXPY-C3 |
| `bisection_init` | `diana_fp_finite`, `diana_fp_abs` | BISECTION-C5, BISECTION-C6 |
| `bisection_step` | `diana_fp_finite` | BISECTION-C13 |
| `cholesky` | `diana_fp_finite` | CHOLESKY-C4 |
| `forward_substitution`, `transpose_substitution` | `diana_fp_finite` | SUBSTITUTION-C5, C6 |
| `lu` | `diana_fp_finite` | LU-C3 |
| `lu_solve` | `diana_fp_finite` | LU-SOLVE-C3 |
| `euler_step` | `diana_fp_finite` | EULER-C3 |
| `newton_init` | `diana_fp_finite` | NEWTON-C8 |
| `newton_step` | `diana_fp_finite`, `diana_fp_abs` | NEWTON-C9, NEWTON-C10 |
| `norm_1` | `diana_fp_finite`, `diana_fp_abs` | NORM-C7, NORM-C8 |
| `norm_2` | `diana_fp_finite`, `diana_fp_abs` | NORM-C9, NORM-C10 |
| `norm_inf` | `diana_fp_finite`, `diana_fp_abs` | NORM-C11, NORM-C12 |
| `rk4_stage`, `rk4_step` | `diana_fp_finite` | RK4-C7, RK4-C8 |
| `simpson`, `trapezoidal` | `diana_fp_finite` | SIMPSON-C3, TRAPEZOIDAL-C3 |

The ASTs of `bisection_mid`, `bisection_result`, `fp_sqrt`, `newton_result` and the three
unchecked kernels contain no helper. After a source change, compare
`grep -o 'Definition f_diana_fp_[a-z]*' verification/clight/*.v` with this table and the specs.
