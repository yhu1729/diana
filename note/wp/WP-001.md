title: ACSL arithmetic on doubles is exact; write rounded values with casts
kind: rule

In ACSL, `+`, `-`, `*` and `/` on `double` operands are exact real arithmetic, not the rounded
binary64 operation the C performs. A contract about a computed value writes the rounding as a
cast: `src/bisection_result.c` ensures `*width == (double)(s->b - s->a)`, the rounded difference
the C stores, whereas `s->b - s->a` alone is the exact difference.

- WP runs with `-wp-model +float` (`script/run_frama_c.sh`), which models the C operations as
  IEEE floating-point arithmetic; only the logic side is exact.
- Comparisons in ACSL (`<`, `<=`, `==`) compare the real values of their operands.
- Constants in ACSL are exact too; a bound such as `DBL_MAX/2` is an exact integer expression
  (WP-002).
- A fact about a rounded value that WP cannot prove goes into a helper outside WP and is proved
  in Flocq (WP-003).
