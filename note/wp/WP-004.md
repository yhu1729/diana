---
id: WP-004
title: How run_frama_c.sh enforces SKIP before it runs WP
kind: fact
path:
  - script/run_frama_c.sh
  - src/bisection_mid.h
related: [WP-003, WP-005]
---
Before WP, `script/run_frama_c.sh` runs `frama-c -metrics` on the same source files with the same
`-cpp-extra-args="-Iinclude -Isrc"` and reads two sections of the metrics report, taking each
function listed there with a non-zero count, that is, each function the sources call:

- "Undefined and unspecified functions": any such function (neither body nor contract) fails the
  run whatever `SKIP` says, because WP would generate a contract for it and assume it.
- "Specified-only functions": a function with a contract but no body fails the run unless its
  name is in `SKIP`, because WP would assume its contract.

A `SKIP` entry is also passed to `-wp-skip-fct`, but only for a source on the command line that
has a line starting in column 0 with a return type followed by the name and `(` (the `grep -E` in
the script), because WP rejects that option for a function without a body. No expectation row
names `src/bisection_mid.c`, so the normal runs never add the option.

The contract on the declaration in `src/bisection_mid.h` states `terminates \true` and
`exits \false` explicitly; for a function without a body Frama-C would otherwise generate those
clauses itself, with a warning.
