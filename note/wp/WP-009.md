---
id: WP-009
title: Each WP row has its own session and cache directory
kind: fact
path:
  - script/run_frama_c.sh
  - .gitignore
related: [WP-008, WP-010]
---
`script/run_frama_c.sh` names a row after its first source file without `.c` (`bisection_init`
for `src/bisection_init.c`) and runs WP with `-wp-session verification/frama-c/session/<row>`,
`-wp-cache update` and `-wp-cache-dir verification/frama-c/cache/<row>`.

- Rows running at once share no WP directory, and a row's cache stays warm across runs because a
  source always maps to the same directory. No two sources share a goal (each file proves its own
  copies of the `src/fp.h` helpers), so the split loses no cache hits.
- `-wp-cache update` reuses a cached verdict or runs the prover and stores its answer, including
  a `Failed` verdict, which later runs replay as `(Cached)` (WP-010).
- The script runs `mkdir -p` on both directories before WP starts. When WP itself created a
  missing cache directory while other rows were starting, goals in every row failed with
  `[Why3 Error] anomaly: Sys_error("No such file or directory")`; creating the directories first
  removed that failure.
- `verification/frama-c/session/`, `verification/frama-c/cache/` and
  `verification/frama-c/report.txt` are git-ignored.
