id: WP-011
title: Nonlinear index bounds proved through the column_end lemma and assertions
kind: rationale
path:
  - src/cholesky.c
related: [WP-007, WP-001, API-028]
---
A matrix access `a[i + j*n]` needs `i + j*n < n*n`, which Alt-Ergo 2.6.4 does not prove from
`i, j < n`: after normalization `n*n`, `j*n` and `n` are independent monomials, and its interval
reasoning signs only products of atoms.

- `src/cholesky.c` declares `lemma column_end: ∀ n, j; 0 <= j < n ==> 0 <= n * (n - 1 - j)`.
  Alt-Ergo proves it in this factored form; equivalent forms (`j*n + n <= n*n`,
  `(j + 1)*n <= n*n`, `a*m <= a*a`) time out, and some forms succeed or fail with the names of
  the bound variables.
- `assert 0 <= n * (n - 1 - j);` at the head of each column body, and the same with `k` inside
  each `k` loop, put the lemma's trigger into the goal, so the assertion is the lemma's
  instance. Once it is a hypothesis, every memory-access, `size_t` no-wrap and `assigns` goal is
  linear in the monomials `n*n`, `j*n` and `k*n`.
- `n*n <= SIZE_MAX` comes from the C check `n > (size_t)-1 / n`, through an assertion Alt-Ergo
  proves directly from the division.
- Not stated: that every entry on or below the diagonal is finite on success. Qed rewrites `n`
  into the inner counter's final value in the outer invariant's preservation goal, which defeats
  instantiation; CHOLESKY-C3 proves the status exactly instead.
